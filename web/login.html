On the odi-oss firmware the safe mode lets you back in with nothing but the stick's power. It keeps your settings, apart from ones that could have locked you out; after you sign in the page names any it reset.

  1. Plug the stick in, wait about 80 seconds, pull it, wait a few seconds.
  2. Do that five times in a row, or three times if the host port is set to 2500BASE-X or HiSGMII or its auto-negotiation is off.
  3. Plug it in and leave it in. That boot is the safe mode.
  4. After a few minutes sign in here with admin / admin. The page opens at System › Access: set a new password there, acknowledge the safe-mode bar and reboot. Do it within 30 minutes: a safe mode nobody acknowledges ends by itself with a reboot.

Not sure which count applies? Do it three times first. If admin / admin is still refused a few minutes after the last plug-in, do it five times.

Each power-up has to end roughly 60 to 110 seconds after power-on. During the safe mode the fibre is off, so there is no internet through the stick. Besides its usual address it answers at 169.254.1.1.

The power is what opens admin / admin. A safe mode the stick entered by itself, after resets it recorded as its own, keeps the saved password; the one exception is five resets in a row within the first minute that leave no record, which count like power cycles. If the stick refuses every password, the saved one included, its settings partition cannot be read: pull it, wait ten seconds and plug it back in once.
